# Earthtrip · 지구여행

Public website deployment files for Earthtrip.

[Open Earthtrip](https://shaunkimdev.github.io/Earthtrip-pages/)

The source repository and its history remain private. This repository contains only browser assets, public camera metadata and the scheduled camera checker.

- Globe: MapLibre GL JS, NASA EOSDIS GIBS, OpenFreeMap, OpenMapTiles and OpenStreetMap.
- Original YouTube broadcasts and Open-Meteo weather.
- Korean and English; installable mobile PWA.
- Daily checks: 18:17 UTC / 03:17 Korea Standard Time. GitHub may delay scheduled jobs.
- New camera destinations are reviewed before addition.

Source build: `9c162daff6aecc9d467ea3603adcdbbd6b504772`.

Open-Meteo's free endpoint is for non-commercial use. Original broadcast and map provider terms apply.
